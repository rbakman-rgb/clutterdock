Public beta

Install ClutterDock in a few minutes.

Builds are currently ad-hoc signed (Mac) and unsigned (Windows). That’s temporary until Apple Developer ID notarization and Windows signing land. The steps below are normal for indie betas.

Get the builds GitHub Releases

macOS 14+

Mac install

Native Swift app. Default hotkey: ⌘⇧D.

1

Download the zip

Get ClutterDock-1.4.7-mac.zip from the download section (release v1.4.8). Universal (Apple Silicon + Intel).

2

Drag to Applications

Unzip, then move ClutterDock.app into /Applications.

3

Right-click → Open

First launch only: right-click the app → Open → Open. Or use Privacy & Security → Open Anyway.

Gatekeeper: “can’t be opened” / unidentified developer

macOS blocks apps that aren’t notarized by Apple. ClutterDock is safe to run from our GitHub Releases; it’s just not Developer ID–notarized yet.

Fix: Finder → right-click ClutterDock → Open (don’t double-click the first time). Confirm Open in the dialog. Alternate: System Settings → Privacy & Security → scroll to the blocked-app message → Open Anyway.

After the first successful open, normal launches work like any other app.

Windows 10 / 11

Windows install

Taskbar + tray launcher. Default hotkey: Ctrl+Shift+D.

1

Download the installer

Prefer ClutterDock-*-setup.exe (installs to a stable folder so you can pin it). The older portable ClutterDock-*-x64.exe unpacks to Temp — antivirus often flags that, and it will not stay on the taskbar.

2

Install and allow if asked

SmartScreen: More info → Run anyway. Bitdefender / other AV: this build is unsigned, not malware — Restore/Allow the file, or add an exclusion for ClutterDock until we ship a signed build.

3

Pin to the taskbar

After it launches, right-click the ClutterDock icon on the taskbar → Pin to taskbar. Then unpin the apps you now open from stacks — that’s how the taskbar gets smaller, same idea as the Mac Dock icon.

SmartScreen / Bitdefender: “virus” or “untrusted”

Windows and antivirus flag apps without a paid Authenticode certificate. ClutterDock is open source (github.com/rbakman-rgb/clutterdock) and only distributed from that repo / this site. Expected for this beta.

SmartScreen: More info → Run anyway.
Bitdefender: Protection → Antivirus → Settings → Exclusions, or restore from Quarantine. Do not use a portable exe from the Downloads Temp unpack if an installer is available.

After install

Get productive fast

Keep in Dock (Mac)

Right-click the Dock icon → Options → Keep in Dock so it’s always one click away.

Hotkey

⌘⇧D on Mac, Ctrl+Shift+D on Windows. Change presets in Settings when available.

Migrating from SlaveDock?

Folders and history migrate automatically. Your SDPRO-… keys still work.

Pro unlock

Settings → Pro. Checkout on the site is still coming; keys work offline once you have one.

Privacy

Local-first. No account. See the privacy page.

Problems?

Open a GitHub Issue with your OS version and what you saw.

Ready to install

Grab the Mac zip or Windows exe, then follow the steps above for the first launch.
