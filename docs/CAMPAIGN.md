## One sentence

ClutterDock turns apps, files, folders, and links into named stacks you open with one hotkey — without replacing the Mac Dock or the Windows taskbar.

## Promise (use this, don't invent)

- Keeps the system Dock / taskbar
- Mixes apps + files + folders + URLs in one stack
- Local-first, no account
- Free forever for daily use (5 stacks / 20 items)
- Mac + Windows
- One-time Pro later ($14.99) — **do not take payment until checkout exists**

## Honesty block (every launch post)

ClutterDock is an **unsigned public beta**.

- **Mac:** first launch is **Right-click → Open** (Gatekeeper). Install notes: https://clutterdock.com/install
- **Windows:** download the **setup** installer, not the portable exe. SmartScreen / Bitdefender may warn because it is not code-signed. Pin the taskbar icon after install.
- **Pro** is designed and priced; **buy buttons are not live** until Lemon Squeezy approves BYC Labs.
- Source is MIT: https://github.com/rbakman-rgb/clutterdock

If a sentence would be false after a stranger downloads tonight, cut it.

## Who this is for

People who pin too much, then hunt. Client work + personal + admin on the same machine. They want order, not a new OS skin.

**Not for:** people shopping Dock replacements (uBar, uDock, ObjectDock), people who will only install App Store / Microsoft Store apps, people who need a signed binary today.

## Success (realistic)

There is almost no public traffic today. A good week-1 is:

- Strangers actually install (GitHub Release asset downloads from IPs that aren't Ronald)
- A handful of real comments / DMs
- No pile-on about malware that we didn't already explain
- A list of bugs from real machines

A bad week-1 is: paid ads, fake social proof, selling Pro that cannot be bought, or Reddit bans.
