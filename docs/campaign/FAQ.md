# Reply scripts

Use these almost verbatim. Short > clever. If you don't know, say you'll check and come back.

---

## Is this a virus? Bitdefender / SmartScreen / Gatekeeper

Unsigned indie build. I haven't bought Apple notarization or Windows Authenticode yet, so the OS and some AV treat it like random software — that's expected, not a hidden payload.

Source is public MIT: https://github.com/rbakman-rgb/clutterdock  
Install notes: https://clutterdock.com/install

Windows: use the **setup** installer. The portable exe unpacks to TEMP and looks worse to antivirus.

Mac: Right-click → Open the first time.

If you don't want to run unsigned software, wait. I'm not going to talk you into ignoring your AV.

---

## Does this replace the Dock / taskbar?

No. That's the point. ClutterDock is a companion. Keep Finder, Safari, whatever you actually want on the Dock. Put the rest in stacks. On Windows, pin ClutterDock and unpin the apps you now launch from stacks.

---

## How is this different from a Dock folder / Start / Spotlight?

A Dock folder is files. Spotlight is search. ClutterDock is a named context: this client, this job, this mode — apps + files + folders + URLs in one place, one hotkey.

---

## Is it free? What's the catch?

Free core is real: launcher, 5 stacks, 20 items each, Recents, hotkey, no account. Pro is a one-time unlock for unlimited / workspaces / extra hotkeys / search. Checkout is **not live**. There is nothing to buy today. You are not the funnel.

---

## Do I need an account? Is my app list uploaded?

No account. Stacks live on your machine. I'm not shipping your layout to a server.

---

## Mac only? Windows only?

Both. Native Swift on Mac 14+. Electron tray on Windows 10/11. Same idea, same license later. Download from https://clutterdock.com/#download

---

## Can I put it on the taskbar?

Yes — that's the Windows setup. Install via setup.exe, then right-click the ClutterDock icon → Pin to taskbar. After that, unpin the apps you launch from stacks so the bar actually gets smaller.

---

## Open source? Can I just build it myself?

Yes. MIT. https://github.com/rbakman-rgb/clutterdock  
That's allowed. Free download exists so you don't have to.

---

## Why should I trust an unsigned app?

You shouldn't on faith. Read the source, wait for notarization, or don't install. I'm not going to pretend Gatekeeper is optional because I haven't paid Apple yet.

---

## uBar / RocketDock / ObjectDock / uDock?

Those replace or skin the Dock/taskbar. ClutterDock does not. If you want a different Dock, I'm the wrong app.

---

## Subscription?

No. Free core stays free. Pro is planned as one-time. No Pro to buy until merchant approval.

## It didn't open on Mac

Right-click the app → Open. Or System Settings → Privacy & Security → Open Anyway. https://clutterdock.com/install

## Windows installer vs portable

Setup installer = the one people should use. Portable is a fallback and trips AV because it unpacks under TEMP.
