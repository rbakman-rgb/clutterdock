# ClutterDock feature film — RON-504

32 seconds, 1920×1080, 30 fps, H.264/AAC, stereo original score.

This is an edited product film made from authentic native app captures, with
camera motion, typography and transitions. It is not an uninterrupted recording
of an interaction. No product interface was generated by AI. The CD identity is
the proposed Signature concept; installing the new app icon is a separate step.

## Source and editorial treatment

- `assets/apps.png`, `search-cl.png`, `search-clock.png`, and `list.png` were
  captured through native computer-use controls from `/Applications/ClutterDock.app`
  on September 25, 2026. The installed Prism preview reports 1.4.10 build 16;
  these captures are evidence of that UI, not a verification of a release install.
- `assets/cd-signature.png` is a standalone refinement of the CD Signature
  proposal, created with the built-in image generator. Prompt: preserve the
  reference's exact white CD ligature, diagonal cuts and cobalt rounded square;
  remove the labels and duplicate small icons; deliver one crisp front-facing
  icon on transparency with restrained depth.
- `render.py` composes the film and synthesizes its original ambient score.
  There is no sampled music, voiceover, or copied reference footage.
- Vitals reference: https://vitalsmac.com/ was reviewed live, including its
  interactive product tabs. Inspiration: clear typography, generous space,
  product-led explanation, blue emphasis and concise privacy messaging.
  The supplied X post's player could not be reliably accessed in this run.

## Render

Requires Python 3, Pillow, NumPy and ffmpeg. The renderer currently uses the
macOS Arial and SF system fonts.

```sh
python3 docs/campaign/feature-film/render.py --stills
python3 docs/campaign/feature-film/render.py
```

Files are written to ignored `output/feature-film/`. If macOS blocks a runtime
from writing into a protected Documents folder, set `CLUTTERDOCK_FILM_OUTPUT`
to a permitted staging directory and copy the final results into the project.

The website uses `website/assets/clutterdock-prism-film.mp4`, its poster and
WebVTT captions. Playback is user-initiated; there is no autoplay or preloaded
video download. The original continuous screen-recording scope of RON-504
remains distinct from this first product-film cut.

## Validation

- ffprobe confirms 32 seconds, 1920×1080 at 30 fps, H.264 video and AAC stereo
  audio at 48 kHz. The complete MP4 decodes without errors.
- All seven scene stills were visually reviewed. The website player reached the
  end; replay, pause and resume worked in Chrome with no media error.
- At a 390×844 viewport, the player measures 354 pixels wide and the document
  has no horizontal overflow. The original viewport was restored after review.
- Local references, poster/caption assets, JavaScript syntax and diff whitespace
  checks pass. The MP4 and WebVTT are served with their expected content types.
- This is a review draft. The public website and installed application icon have
