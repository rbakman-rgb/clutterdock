## How keys work with Lemon Squeezy

ClutterDock unlocks with **offline HMAC keys** (`SDPRO-XXXX-YYYY-ZZZZ`) generated by
`scripts/generate-license.swift` / `windows/scripts/generate-license.js` using the secret in
`scripts/private/license-secret.txt`. The app does **not** call Lemon Squeezy to validate.

| Layer | Who |
|-------|-----|
| Payment, tax, receipt | Lemon Squeezy |
| Unlock string in Settings → Pro | Our `SDPRO-…` generator (`docs/KEY_OPS.md`) |
| Day-1 fulfillment | Manual: pay → generate `SDPRO` → email buyer |
| Later (RON-366) | `order_created` webhook → generate `SDPRO` → email |

**Do not** rely on Lemon Squeezy’s built-in license keys for unlock — the app will reject them.
You may leave “Generate license keys” **off**, or on only if you ignore those keys in email.
